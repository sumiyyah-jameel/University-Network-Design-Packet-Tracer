# University-Network-Design-Packet-Tracer
Cisco Packet Tracer-based university network simulation with VLANs, static routing, DHCP, DNS, FTP, Email, and Web Server services.

## Project Overview

This project simulates a complete university campus network using Cisco Packet Tracer. The network connects the Main Campus with the Branch Campus using static routing while providing multiple network services including DHCP, DNS, FTP, Email, HTTP, and VLAN segmentation.

## Features

- Multi-campus topology
- VLAN Configuration
- Static Routing
- DHCP
- DNS
- FTP Server
- Email Server
- Web Server
- End-to-End Connectivity
- Inter-VLAN Communication

## Technologies Used

- Cisco Packet Tracer
- Cisco Routers 2911
- Cisco Catalyst 2960 & 3650 Switches
- Static Routing
- VLANs
- FTP
- SMTP
- POP3
- HTTP
- DHCP
- DNS
